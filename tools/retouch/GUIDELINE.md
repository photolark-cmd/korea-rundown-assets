# 학사모 사진 구조 가이드 (사용자 정본, 2026-09-10)

사용자가 준 가이드라인 그림에서 옮긴 것. **보정의 목표 구조**이며,
"모자 수평·고개 수직·어깨선 좌우 일치·옷매무새"를 구체적인 선으로 푼 것이다.
편집할 때 아이의 얼굴·몸·팔·가운·모자를 이 기준에 맞춘다.

## 중심축 (세로)

화면 중앙을 지나는 **세로 축 하나**가 기준이고, 구도는 그 축에 대해 좌우 대칭이다.
이 축에 맞춰야 하는 것:

- 학사모의 좌우 중앙
- 얼굴의 좌우 중앙 (미간~인중~턱 끝)
- 몸통(가운 앞섶)의 중앙
- 두 손이 잡은 졸업장의 중앙

## 수평선 (위에서 아래로)

| 선 | 무엇을 맞추는가 |
|---|---|
| 1. 모자 윗선 | 학사모 판의 윗변이 **수평** |
| 2. 모자 아랫단(테) | 모자 띠가 **수평** — 1번과 나란해야 모자가 안 기운다 |
| 3. 입선 | 입꼬리 좌우가 같은 높이 = **고개가 안 기움** |
| 4. 어깨선 | 좌우 어깨가 같은 높이 |
| 5. 소매 끝선 | 좌우 소매(팔) 끝이 같은 높이 |

## 삼각형 (윗변 구조)

모자 꼭대기를 꼭짓점으로, 아래로 내려가며 가운이 퍼지는 **이등변삼각형**.
좌우로 퍼지는 폭이 중심축 기준으로 같아야 한다. 한쪽 소매만 처지거나
가운 한쪽이 더 벌어지면 이 삼각형이 기운다.

## 마름모 (아랫변 구조)

소매 끝선에서 가장 넓어졌다가 아래로 다시 좁아지는 마름모.
좌우 소매 끝이 중심축에서 **같은 거리**여야 한다.

## 도구와의 대응

| 가이드 항목 | 도구 |
|---|---|
| 모자 윗선 수평 | `pose_check` 의 모자 각도 → `level_hat` |
| 고개 수직 | `pose_check` 의 고개 각도 → `head_tilt` |
| 어깨선 수평 | `pose_check` 의 어깨 각도 → `level_shoulders` |
| 중심축 정렬 | `guide_check` 의 중심 어긋남 |
| 소매 끝선 수평·좌우 대칭 | `guide_check` 의 소매 끝 높이차·폭 비 |

## 주의

이 구조는 **기준점이지 강제값이 아니다.** 아이가 자연스럽게 서 있는 모습을
해치면서까지 선에 맞추지 않는다. 각도 교정은 한 번만 걸고(반복하면 발산),
결과를 보고 판단한다.

# 학습 자료 원칙 (2026-09-10 확정)

## 촬영자 확인이 먼저다

사용자가 두 번 지적했다 — 내가 고른 사진이 자꾸 남이 찍은 것이었다.
저장소 폴더에 있다고 사용자 작업물이 아니다. 실측 결과:

  자동 선별 519쌍 중 **사용자 바디로 찍은 것은 18쌍뿐**, 나머지 501쌍은 남의 촬영.

**기종으로는 못 가린다.** 저장소에 같은 5D Mark III 를 쓰는 다른 사람이 있다.
**바디 시리얼**이 유일한 판별자이며, 사용자 바디 시리얼은
`tools/retouch/work/camera.json` 에 있다(개인 장비 식별자라 저장소에 안 올린다).

`learn_from_folder.py` 의 `check_cameras()` 가 학습 전에 자동으로 확인하고,
등록된 카메라가 아닌 사진이 섞여 있으면 경고한다.

## 그래도 사람이 골라야 한다

카메라는 **촬영자**를 알려 주지 **보정자**를 알려 주지 않는다. 스튜디오에서는
찍은 사람과 보정한 사람이 다를 수 있다. 그래서 자동 선별은 안전망이 아니라
**내 실수를 잡는 그물**일 뿐이고, 학습 자료는 사용자가 직접 넣은 것만 쓴다
(바탕화면 `보정견본`).

## 스타일이 섞이면 배울 게 없어진다

같은 지표로 두 자료를 재 보면 성향이 갈린다 (표본 각 90쌍):

| 지표 | 저장소(남) | 사용자 본인 |
|---|---|---|
| 피부 결 남은 비율 | 0.945 | **0.740** |
| 표준편차 | 0.345 | **0.094** |

사용자는 피부 결을 26% 줄이는데 저장소 자료는 5%만 줄인다. 더 중요한 건
**표준편차** — 저장소 자료는 여러 사람이 제각각 보정한 것이 섞여 있다.
모델은 평균을 배우므로, 섞으면 "아무것도 확실하게 하지 않는" 모델이 된다.
**적어도 일관된 것이 많지만 제각각인 것보다 낫다.**
