# 인물 사진 일괄 보정 (`tools/retouch/`)

본인이 직접 보정한 **원본/보정본 쌍 몇백 장**으로 보정 방식을 학습시켜, 새 사진에 일괄
적용합니다. 잡티·피부 결·눈·치아 같은 **제자리 보정**과 **얼굴형 변형**(리퀴파이)을
따로 배우고, 색은 기존 `learn-preset.mjs`의 프리셋을 그대로 씁니다.

학습·적용 모두 **사용자 PC**에서 돌립니다 (3080 Ti 기준 몇백 쌍 학습 1~2시간).
사람 사진은 이 public 저장소에 올리지 않습니다.

## 준비 (최초 1회, PC)

```bash
python -m pip install -r tools/retouch/requirements.txt
# GPU 학습용 torch는 pytorch.org/get-started 에서 CUDA 빌드로 (예: --index-url https://download.pytorch.org/whl/cu126)
```

얼굴 랜드마크 모델(3.7MB)은 처음 실행할 때 `tools/retouch/models/`에 자동으로 내려받습니다.

## 순서

```bash
# 1. 쌍 → 학습 데이터 (얼굴 크롭, 정렬, 마스크, 변형량)
python tools/retouch/prepare.py pairs/ --out work/ [--preset cvs-mine]

# 2. 얼굴형 모델 (몇 초)
python tools/retouch/train_geom.py work/

# 3. 질감 모델 (GPU, 1~2시간). work/previews/ 에서 진행 상황을 눈으로 확인
python tools/retouch/train_tex.py work/ --epochs 40

# 4. 새 사진 일괄 적용
python tools/retouch/retouch.py 촬영본/ --out 결과/ --data work/ [--preset cvs-mine]

# 5. 검수: tools/retouch/review.html 을 브라우저에서 열고 두 폴더 선택
```

`pairs/`는 `learn-preset.mjs`와 같은 형태입니다 (`before/` + `after/` 같은 파일명, 또는
`이름.before.jpg` / `이름.after.jpg`).

### 학습 자료 조건

- **원본과 보정본은 같은 해상도, 같은 프레임.** 크롭·리사이즈된 쌍은 건너뜁니다.
  크롭은 보정이 끝난 뒤 별도로 하세요.
- 얼굴이 하나인 사진이 좋습니다. 여럿이면 **가장 큰 얼굴**만 다룹니다.
- 학습 데이터(`work/`)는 쌍당 PNG 4장, 얼굴 폭 1024 기준 **쌍당 약 10MB** 잡으세요.

### 적용 옵션 (`retouch.py`)

| 옵션 | 뜻 |
|---|---|
| `--geom-strength 0.7` | 얼굴형 변형을 학습한 것의 70%만 |
| `--tex-strength 0.7` | 질감 보정을 70%만 |
| `--no-geom` / `--no-tex` | 한쪽만 적용 |
| `--preset id` | 색 프리셋 먼저 적용 (**학습 때와 같은 것**으로) |

얼굴을 못 찾은 사진은 색 프리셋만 적용하고 마지막에 목록으로 알려줍니다.

## 검수 (`review.html`)

원본 폴더와 결과 폴더를 고르면 같은 이름끼리 나란히 보여줍니다.
`1` OK · `2` 손봐야 함 · `Space` 원본을 같은 자리에 겹쳐 보기 · **손봐야 할 목록** 버튼으로
직접 만질 파일명만 뽑습니다. 표시는 브라우저에 저장돼 창을 닫아도 남습니다.

## 어떻게 동작하나

1. **정렬** — 보정본에서 얼굴형을 바꿨으면 원본과 픽셀이 어긋납니다. 두 사진의 468개
   랜드마크로 보정본을 원본 얼굴 위치로 되돌려 놓아(piecewise-affine warp)
   픽셀 단위로 맞춘 뒤, **얼마나 움직였는지**는 따로 기록합니다.
2. **얼굴형 모델** — 랜드마크 이동량을 얼굴 폭 단위로 정규화해 회귀. 평균 이동량 모델과
   얼굴 생김새에 따라 달라지는 회귀 모델을 교차검증으로 비교해 나은 쪽을 씁니다.
3. **질감 모델** — 정렬된 쌍으로 작은 U-Net을 학습. 출력은 **원본에 더할 차이**이고
   얼굴 게이트 마스크 안에서만 더해지므로 배경·머리는 건드리지 않습니다.
   손실: L1 + 라플라시안 L1(뭉개짐 방지) + 선택적으로 VGG 지각 손실(`--perceptual`).
4. **적용** — 색 프리셋 → 얼굴형 워핑 → 질감 모델 → 원본 해상도에 페더링해 되붙임.
   EXIF는 유지하고 회전 태그만 정리합니다.

## 한계 (미리 알고 시작)

- 얼굴 바깥(목·손·몸매)은 안 건드립니다. 얼굴 안의 보정만 배웁니다.
- 부분적으로만 한 보정(어떤 사진은 하고 어떤 사진은 안 한 것)은 평균으로 희석됩니다.
  일관되게 보정한 쌍일수록 결과가 좋습니다.
- 이 세션 환경에서는 합성 얼굴 14쌍으로 **배관이 끝까지 도는 것까지만** 확인했습니다.
  실제 품질은 PC에서 진짜 쌍으로 학습해 봐야 압니다. `train_tex.py`가 출력하는
  "검증 오차 vs 보정 안 했을 때"와 `previews/`가 그 판단 기준입니다.
