# 사진 보정 (`tools/photo-fix/`)

왼쪽에 원본, 오른쪽에 보정본을 놓고 비교하며 고치는 도구입니다.
**설치도 서버도 필요 없습니다.** `index.html`을 브라우저에서 그냥 열면 됩니다.
사진은 어디로도 업로드되지 않고 전부 브라우저 안에서 처리됩니다.

```
tools/photo-fix/index.html   ← 더블클릭해서 열기
```

## 쓰는 순서

1. **사진 열기** (또는 창에 끌어다 놓기) — 여러 장 한꺼번에 가능
2. **자동 보정** — 채널별 히스토그램을 펴서 색 틀어짐과 뿌연 느낌을 먼저 잡습니다
3. **프리셋** 고르기 → 슬라이더로 미세 조정 (슬라이더 더블클릭 = 그 항목만 초기화)
4. 저장 크기 고르고 **저장** / 여러 장이면 **전체 저장**

`←` `→` 키로 사진을 넘깁니다. 미리보기는 긴 변 1400px로 줄여서 처리하고,
저장할 때만 원본 해상도에 같은 보정을 다시 먹입니다.

저장 크기는 블로그 규격에 맞춰 두었습니다.

| 선택 | 쓰임 |
|---|---|
| 원본 크기 | 보관용 |
| 가로 1600 | 본문 삽입용 |
| 1200×630 | 영문 블로그 썸네일 (가운데 기준 잘림) |
| 1080×1080 | 국내 블로그 썸네일 (가운데 기준 잘림) |

## 프리셋을 직접 학습시키기

기본 프리셋 4개는 손으로 맞춘 출발점일 뿐입니다.
**직접 보정한 before/after 쌍을 주면 그 보정 방식을 뽑아냅니다.**

```bash
node tools/learn-preset.mjs <폴더> --name "야간 편의점" [--id cvs-mine]
```

폴더는 둘 중 아무 형태나 됩니다.

```
pairs/before/IMG_1234.jpg + pairs/after/IMG_1234.jpg     (같은 파일명)
pairs/IMG_1234.before.jpg + pairs/IMG_1234.after.jpg     (한 폴더에)
```

결과는 `tools/photo-fix/presets.js`에 쌓이고, `index.html`을 다시 열면
프리셋 목록에 나타납니다.

### 학습 자료 만들 때 지켜야 할 것

- **10~30쌍**이면 충분합니다. 그 이상은 정확도가 크게 오르지 않습니다.
- **크롭·회전은 보정 뒤에** 하세요. 원본과 보정본의 화면이 다르면 서로 다른
  장면의 히스토그램을 비교하게 됩니다. 비율이 어긋난 쌍은 경고하고 건너뜁니다.
- **상황을 섞지 마세요.** 야간 실내와 주간 실외를 한 폴더에 넣으면 평균이
  둘 다 아닌 값으로 수렴합니다. 폴더를 나눠 프리셋을 따로 만드세요.
- 부분 보정(브러시·마스크·잡티 제거)은 학습되지 않습니다. 이 도구가 배우는 것은
  **사진 전체에 고르게 적용된 색·밝기 변화**입니다.
- JPEG로 충분합니다. RAW는 미리 JPEG/PNG로 내보내 주세요.

학습이 끝나면 쌍들이 서로 얼마나 일관됐는지, 유독 튀는 사진이 어느 것인지
알려줍니다. 편차가 크다고 나오면 폴더를 나누라는 뜻입니다.

## 원리 (알아두면 결과를 예측할 수 있습니다)

한 쌍에서 채널별로 **히스토그램 매칭**을 합니다. 원본의 밝기 v가 보정본에서 어느
밝기로 갔는지 누적분포로 대응시키면, 화이트밸런스·노출·검정점·톤커브가 한꺼번에
**256칸 표(LUT) 3개**로 떨어집니다. 쌍마다 표를 만들어 평균 내고, 계단이 생기지
않게 매끄럽게 다듬은 것이 프리셋입니다.

합성한 쌍으로 검증했을 때 원래 걸었던 보정과의 오차는 **평균 0.7단계 / 255**,
그 프리셋을 앱에서 다시 적용해 실제 보정본과 비교했을 때 **평균 2단계 / 255**였습니다.
눈으로는 구분되지 않는 수준입니다.

밝기·색 전체에 걸리는 보정만 다룹니다. 부분 보정, 노이즈 제거, 렌즈 왜곡,
객체 제거는 이 방식으로는 되지 않습니다.
