# 뉴스 트리거 해설 플레이북

> 대상: 영문 블로그 ([`content-guide-us.md`](content-guide-us.md)).
> 국내용에도 같은 방식이 적용되지만 채널 조건은 [`content-guide-kr.md`](content-guide-kr.md)를 따르세요.

## 전제 — 속보로 경쟁하지 않습니다

통신사가 **"무슨 일이 있었다"**를 씁니다. 우리는 **"그래서 얼마고, 미국과 어떻게 다른가"**를 씁니다.

Yonhap English·Korea Herald와 속도로 붙으면 집니다. 그런데 그들이 안 쓰는 자리가 있습니다 —
숫자를 환산하고, 미국과 비교하고, 외국인에게 무슨 의미인지 설명하는 자리. 거기가 비어 있습니다.

| | 뉴스 재작성 | 뉴스 트리거 해설 |
|---|---|---|
| 목표 리드타임 | 몇 시간 (이길 수 없음) | **24~48시간** |
| 이미지 | 기사 사진 (위험) | 직접 제작 (위험 0) |
| 수명 | 3일 | 몇 달~몇 년, 갱신하며 재사용 |
| 경쟁 | 통신사와 정면 | 사실상 없음 |

---

## 1. 어떤 뉴스가 트리거인가

### 되는 것

- **요금·수수료 변경** — 교통, 배달, 공공요금, 통신비
- **제도 변경** — 비자, 건강보험, 세금, 면세, 입국 절차
- **정기 통계 발표** — 물가, 인구, 점포수, 진료비
- **외국인에게 직접 영향 있는 규정** — 이게 가장 반응이 좋습니다
- **순위·기록 발표** — "한국이 OECD 중 최저/최고" 류

공통점: **숫자가 있고, 미국 대응값이 존재하고, 독자가 영향을 받습니다.** 셋 중 하나라도 없으면 넘기세요.

### 안 되는 것

- 사건사고·정치 — 브랜드와 무관하고 경쟁도 심함
- 연예·K팝 — 이미 allkpop·Soompi가 장악
- 이미 미국 매체가 크게 다룬 것 — 늦었습니다

## 2. 어디를 감시하나

| 소스 | 무엇 |
|---|---|
| 정책브리핑 `korea.kr` | 전 부처 보도자료. **1차 출처** |
| 각 부처·공사 보도자료 | 요금·제도 원문 |
| 통계청 공표 일정 | 발표 예정일이 미리 공개됨 |
| 네이버 뉴스 경제/생활 | 국내 반응 확인용 |
| Reddit `r/korea` `r/Living_in_Korea` | 외국인이 실제로 뭘 궁금해하는지 |

> ⚠️ 링크는 이 문서를 쓴 환경에서 접속 검증을 하지 못했습니다(네트워크 정책). 처음 쓸 때 확인해 주세요.

### 가장 큰 지렛대: 발표 일정은 미리 공개됩니다

통계 공표와 요금 개정은 **예고**됩니다. 발표 전에 글의 뼈대·비교표·썸네일 행을 미리 만들어 두고
숫자만 비워두면, 발표 당일 **한두 시간 안에** 나갑니다. 속도 문제가 여기서 대부분 해결됩니다.

---

## 3. 작업 순서 (24시간)

| 시점 | 할 일 |
|---|---|
| T+0 | 뉴스 인지 → **보도자료 원문 확보**. 기사가 아니라 원문 |
| T+1h | 각도 결정 — 얼마 / 왜 바뀌었나 / 미국과 비교 중 **하나만** |
| T+2h | 미국 비교값 확보 (BLS·FRED·KFF 등, [US 가이드 §2](content-guide-us.md)) |
| T+3h | 비교표 작성 → 본문 |
| T+4h | 썸네일 렌더 (CSV 한 줄) + 본문 이미지 |
| T+5h | 발행 → 내부링크 연결 → 소셜 |

각도를 하나로 좁히는 게 속도의 핵심입니다. 세 개 다 담으려다 이틀 걸립니다.
나머지 두 각도는 **다음 편**으로 씁니다 (US 가이드 §2의 "숫자 하나 → 여러 편").

## 4. 글 골격 (속보 대응판)

[`post-template-us.md`](post-template-us.md)의 축약형입니다.

```
# [숫자 + 변화 + 비교]  예: Seoul's Subway Fare Just Went Up — Here's What It Costs Now vs NYC

*Updated: [날짜] · Exchange rate: ₩____ = $1*

[첫 문단에 결론. 바뀐 값과 달러 환산.]

## What changed
[사실관계 3~4줄. 시행일 명시.]

## Korea vs the US
[비교표 — 텍스트 표로]

## Why it changed
[구조·배경. 여기가 통신사가 안 쓰는 부분]

## What it means if you're here
[독자 행동 지침]

## Related
[기존 시리즈 글 내부링크]

## Sources
[보도자료 원문 링크 + 미국 측 출처]
```

**내부링크를 반드시 거세요.** 뉴스 글의 스파이크 트래픽을 수명 긴 기존 글로 흘려보내는 게
이 방식의 진짜 수익 지점입니다.

## 5. 저작권 안전선 ★ 이 절만은 지켜주세요

| 대상 | 되는 것 | 안 되는 것 |
|---|---|---|
| 기사 사진 | — | **무단 사용 금지.** 국내 통신사·신문사는 실제로 적극 대응합니다 |
| 기사 본문 | 링크 + 한두 문장 요약 | 문단 복제, 번역 전재 |
| 보도자료 | 사실·수치 인용, 출처 표기 | — |
| 보도자료 첨부 이미지 | 공공누리 유형 확인 후 표기 | 유형 확인 없이 사용 |
| 표·그래프 | **직접 재구성** | 캡처해서 그대로 게시 |

원칙 하나로 줄이면: **사실과 숫자는 자유롭게, 표현과 이미지는 직접.**

기사 사진이 필요하다고 느껴지면 그건 대개 §6으로 해결됩니다.

---

## 6. 이미지

뉴스 글일수록 이미지가 없으면 밋밋합니다. 다만 **기사 사진을 쓰지 않고도** 채울 수 있습니다.
무엇을 어떻게 만들지는 [US 가이드 §5 시각 자료](content-guide-us.md#5-시각-자료--글이-숫자만-있으면-안-읽힙니다)에 정리해 뒀습니다.

속보 대응에서 가장 빠른 조합:

1. **썸네일 1장** — CSV 한 줄, 몇 초
   ```bash
   node tools/render-thumbnails.mjs --profile us --skip-existing
   ```
2. **직접 찍은 사진 1~2장** — 개찰구, 매대, 영수증. 평소에 찍어서 쌓아두면 여기서 씁니다
3. **비교 차트 1장** — 표와 같은 데이터, 시각적 반복

---

## 7. 발행 후

- **갱신 일정을 잡으세요.** 요금·제도는 또 바뀝니다. 그때 새 글을 쓰지 말고 **기존 글을 갱신**하면
  색인 자산이 쌓입니다
- 갱신할 때 상단 `Updated` 날짜를 바꾸고, 무엇이 바뀌었는지 한 줄 남기기
- 스파이크가 지나간 뒤 유입이 남는지 확인 → 남으면 그 소재는 시리즈로 확장

---

## 8. 발행 전 체크리스트

- [ ] 1차 출처(보도자료 원문)를 직접 확인했는가 — 기사 재인용이 아닌가
- [ ] 시행일·기준일을 명시했는가
- [ ] 미국 비교값이 같은 표에 있는가
- [ ] 환율과 기준일을 적었는가
- [ ] **기사 사진을 쓰지 않았는가**
- [ ] 이미지가 최소 2장 있는가 (썸네일 + 본문)
- [ ] 기존 시리즈 글로 내부링크를 걸었는가
- [ ] 갱신 예정 시점을 메모해 뒀는가
